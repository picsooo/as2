# ESASOUD V2 — « Acier blanc » (Light)

Proposition V2 light pour ESASOUD Welding & Cutting. Direction Swiss Modernism industriel — fond blanc, typographie condensée, bandes jaune de repère.

## Fichiers

```
├── index.html          ← Page d'accueil
├── produit.html        ← Fiche produit Caddy Arc
├── assets/css/style.css
├── assets/js/main.js
├── vercel.json
├── download-images.sh
├── PROPOSITION.md
└── README.md
```

## Déploiement

1. Push sur GitHub
2. Connecter sur Vercel → Framework: Other → Output: `.`
3. `cleanUrls` activé dans vercel.json

## Différences avec V1 (Forge noire)

| | V1 — Forge noire | V2 — Acier blanc |
|---|---|---|
| Fond | Charbon #0C0F14 | Blanc #FFFFFF |
| Typo display | Bebas Neue | Barlow Condensed |
| Style | Grain métallique, glow | Swiss grid, ombres nettes |
| Signature | Ligne lumineuse jaune | Bande latérale jaune 4px |
| Slider | Centré, progress bars | Aligné gauche, compteur |
| Cards | Rounded 12px | Sharp 4px |
| Footer | Très sombre | Navy #0F172A |
